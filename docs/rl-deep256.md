# 256 层自博弈训练和服务器吞吐

2026-09-11。训练机是 RTX 3080 Ti 12 GB、10 vCPU、30 GB 内存，PyTorch 2.12.1+cu130。

`entity-gru-resnet` 已支持可变深度。`rl/deep256.sh` 创建策略塔和价值塔各 256 个 Linear 的新实验，每塔 64 个残差块，隐藏宽度 128。两层实体注意力和每个玩家独立的 GRU 保留，参数总量 9,860,862。256 统计塔内的 Linear，两个塔独立，不是 256 层 Transformer。

保留上一场敌方阵容、界面允许查看的最近两场公开战况和 GRU。训练继续使用八人自博弈、历史神经网络对手池和合法动作掩码。256 层从随机权重开始，不能把 64 层检查点直接当作 256 层续训。

## 已做的采样优化

- 条件动作树的大小和父节点映射在建模时计算，省去每个决策批次八次 GPU 标量读取。新增缓存不写入 state_dict，旧模型仍可严格加载。
- 新字符串先在 CPU 组成一个字节张量，再整体传到 GPU，减少逐字符串的小传输。
- 历史对手和评估只算策略与记忆，不计算价值塔，也不传回无用的价值及 log probability。学习席位仍保存完整 PPO 数据。
- 每个策略批次的动作一出来，就让对应 Node 模拟器执行，与下一个策略批次的推理重叠。每局仍按原来的动作顺序推进，各席位独立的随机数和记忆不变。
- 采样日志新增 `inference_seconds`、`simulator_wait_seconds`、`inference_batches`、`mean_inference_batch`。等待时间只统计推理后未完成的模拟器等待；二者包含重叠工作，不能解释成 CPU/GPU 的纯计算时间。

本地用固定旧代码对照，CPU 输出、梯度完全一致，旧 state_dict 严格加载通过。自动测试覆盖 64/256 层各层梯度与权重更新、PPO burn-in、一致的动作概率、跳过价值分支以及模拟器和推理重叠。

## 实测与默认配置

以下是在 64 层四小时任务同时运行时测得，采用固定早期对局观测，推理缓存预热。推理吞吐不等于完整训练吞吐，也不能说明棋力。

| 256 层 GPU 推理批量 | 同算策略和价值 | 只算策略 |
| --- | ---: | ---: |
| 1 | 34.0 ms/批 | 19.6 ms/批 |
| 8 | 37.8 ms/批 | 21.9 ms/批 |
| 32 | 44.9 ms/批 | 28.8 ms/批 |

用三个不同的冻结神经网络对手、四个学习席位，每环境限制 128 个动作进行采样短测。不同并行数使用同一组种子的前缀，局数不同；所有截断局只用于性能测试，不进入 PPO。

| 模拟器进程数 | 采样动作/秒 | 平均实际推理批量 |
| --- | ---: | ---: |
| 4 | 45.5 | 1.63 |
| 12 | 91.1 | 3.41 |
| 24 | 138.7 | 6.14 |

这台机器上的短测支持先用 24 个模拟器，48 局一轮，以填大按历史模型拆分后的推理批次。24 个进程会交替等推理和执行，并非 24 个核持续满载。正式运行仍应观察 CPU、内存、完整局耗时和学习样本/秒，不能把短测当作最优并行数的证明。

PPO 序列批量从 4 提到 16，每条 16 步，burn-in 为 8，最多一次优化 256 个有效或填充位置，两个 epoch，学习率 3e-5。更大的批量改变梯度统计和每轮更新次数，必须记录为新实验配置。先维持 FP32；混合精度和编译尚未验证，不默认开启。

完整自博弈验证已完成 4 局、3,639 个学习样本和 32 次 Adam 更新。全程约 95.1 秒，其中采样 76.5 秒、PPO 更新 17.5 秒，CUDA 峰值分配约 1,693 MiB。平均 KL 为 0.00663，没有触发 KL 提前停止。检查点在 `rl/runs/deep256-smoke/latest.pt`。这轮使用 4 个环境、序列批量 16，首轮八个席位均为学习策略；不能把它的速度和后续混合历史对手的速度直接比较。峰值是该进程的 PyTorch 分配量，不含其他进程或全部 CUDA 保留内存。

## 使用

服务器的独立目录是 `/root/autodl-tmp/tavern-selfplay-deep256-20260911`。训练包保留正在训练的同一版模拟器：sourceHash 为 `9074e697a84044483b109afa0900472cba382fbdeca99dfb01c70ef1396bb0ad`。工作区后续规则修改不会自动进入这个固定包。

```bash
export TAVERN_RL_PYTHON=/root/miniconda3/bin/python
export PATH=/root/autodl-tmp/runtime/node/bin:$PATH
bash rl/run.sh test

# 默认只运行一轮，避免误开长任务。需要持续训练时明确增加迭代数。
bash rl/deep256.sh

# 完整对局的小规模验证
bash rl/deep256.sh --workers 4 --games-per-iteration 4 \
  --output rl/runs/deep256-smoke-new

# 完整策略的 CPU/GPU 延迟对比
bash rl/run.sh profile --output rl/runs/profile.json

# 有意截断的采样测速，不保存模型、不进行 PPO
bash rl/run.sh profile --depths 256 --devices cuda --rollout-only \
  --rollout-workers 4 12 24 --rollout-steps 128 \
  --output rl/runs/rollout-profile.json
```

已经运行的 64 层任务固定在另一个目录，本次不修改其源码、参数或停止时间。它于北京时间 11:18:03 启动，四小时时限约为 15:18:03，进程退出清理最多再需约十秒，保留最后一次完整检查点。到点停止训练不会自动关闭租赁实例。
