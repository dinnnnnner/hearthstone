# 剩余金币奖励的移除

2026-09-15 已删除结束招募时的剩余金币扣分。当前训练使用终局排名回报，按配置追加第一名奖励。详细公式见 [训练流程](rl-training.md#奖励)。

## 当前行为

采样热路径不再读取结束动作前的金币来计算奖励，不创建八席位逐步扣分列表，也不维护扣分统计。新任务不保存 `unused_gold_penalty`；续训时删除旧字段，并写入 `reward_mode = placement_only`。`--unused-gold-penalty` 已从训练与群体训练入口移除，不能再通过这个参数重新启用。

第一名奖励独立保留。当前服务器指定 `first_place_bonus = 1`，因此第一名 +2、第八名 −1。搜索也已移除金币扣分计算，旧导出文件里的元数据不再触发该惩罚。

原有权重包含过去训练的影响，移除奖励不会立即让模型忘记旧行为。后续通过新目标继续训练，并用固定对手评估。

## 历史兼容

早期实现每次结束招募扣 `0.01 × 剩余金币`，并把逐步奖励与终局分数合并。对应日志、旧检查点和带日期的部署记录保留原值，以便复现实验。

`rewards.py` 的旧数学函数和 GAE 对逐步奖励的支持仍保留用于历史测试，但当前采样与 PPO 入口不调用金币惩罚函数。新命令不应再传“系数 0”来关闭它，计算路径已经删除。
