# 按动作价值决策

2026-09-16 新增 `--action-value`，模型版本 `soft-q-v1`。64、256、1024 层保留原有实体注意力、GRU、两条残差塔及训练状态，在逐牌金币估值的基础上改为学习每个合法动作的后续收益。

## 估值与选择

逐牌估值 `card-cash-v1` 的单位是金币等价；动作 Q 的单位是后续训练回报。两者分开训练。铜须、战吼牌、当前金币、回合、血量和酒馆等级通过共享注意力及记忆参与判断。

所有合法动作，包括买牌、卖牌、刷新、升本、出牌和结束回合，在同一回报尺度比较。商店牌估值低时，模型仍需比较刷新、升本及其他操作；代码没有“低于某金币数就刷新”的固定阈值。

设旧条件策略的对数概率为 `log p`，新增类型和来源残差为 `r`，温度 `T=0.2`：

```
A = T * log p + r
pi = softmax(A / T)              # 只包含合法动作
Q = V + A - sum(stop_gradient(pi) * A)
```

因此 `sum(pi * Q) = V`，最高概率动作也是最高 Q 动作。训练按 pi 采样以保留探索；直接推理取最高 Q 的合法动作。显式开启线上搜索时，搜索仍可覆盖这个选择。

新增两个线性层，从零初始化：`action_value_type` 与 `action_value_source`。旧策略的概率和 V 在迁移初始保持不变，原参数与 Adam 动量保留。初始 Q 只是由旧策略构造的起点，不表示已经校准。

## 如何训练

持续对局每两个回合更新。真实动作 Q 拟合该玩家实际奖励与边界 V 计算的 lambda return；V 同时拟合同一目标。另一条监督来自同局面不同动作的成对随机续演，各候选 Q 拟合各自平均后续回报，用成对标准误降低高噪声比较的权重。即使候选平均回报相同，仍可用于绝对值校准。

动作 Q 使用 Huber 损失。此模式不使用 PPO 裁剪目标、KL 提前停止、分支策略交叉熵或熵奖励；探索由温度分布提供。战斗/资源预测、逐牌金币校准仍保留。分支模拟与真实轨迹分开，私人模拟状态不进入网络输入。

名次奖励和已有第8回合一次性升本奖励沿用当前配置，没有新增剩金币惩罚。短分支末端仍依赖冻结 V，估值可能有偏差；它不是精确最优解。需要用实际对局评估强度，不能仅凭回归损失下降判断学好了经济。

## 使用和兼容

续训在原命令上追加 `--streaming --counterfactual --card-value --action-value`；也支持 `TAVERN_ACTION_VALUE=1`。检查点保存 `model_spec.action_values` 和 `config.action_value`，恢复时自动使用同一架构与温度，不能切回普通 PPO。

旧检查点仍可加载；新检查点要求包含本版动作估值代码的加载器。训练仍沿用引擎现有每席每回合64次操作上限，本次没有修改游戏规则或动作编码。
