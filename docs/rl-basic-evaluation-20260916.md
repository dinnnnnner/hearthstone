# 本地场面与经济评分器

实现见 `rl/basic-evaluation.ts`。评分器本身不含神经网络，后续已接入本地小规模训练验证，没有修改线上模型或远程训练任务。训练入口见 [接入说明](rl-basic-feedback.md)。

## 评分规则

总分等于场面分与经济分。默认权重是人工设置的实验参数，既不代表金币价格，也不代表胜率或最终名次。

| 项目 | 默认计算 |
| --- | --- |
| 场面身材 | 场上攻击之和＋生命之和 |
| 圣盾 | 额外加一次该随从的攻击值 |
| 风怒 | 额外加半次该随从的攻击值 |
| 复生 | 额外加 `0.5 ×（卡牌原始攻击＋1 生命）`，不复制已获得的全部增益 |
| 手牌潜力 | 手牌随从身材与关键词分的 25%，不算成已经上场的战力 |
| 当前金币 | 招募中每枚 1 分；结束招募后的比较记为 0 |
| 随从资产 | 场上及手牌随从每个记 1 分普通出售本金，金色也不机械按三份计算 |
| 下回合收入 | 下一回合基础收入与已知额外金币，应用金币上限后乘 0.8 |
| 免费刷新、法术折扣 | 各每单位 0.5 分，各最多计 3 单位 |
| 酒馆等级 | 每比一级高一级加 3 分机会价值 |

输出包含各项贡献、逐张卡牌明细、资源原始数值以及未定价的效果。所有权重均可覆盖，输入数值必须有限且非负。英雄生命可非正，表示已被淘汰。比较操作路线时，存活路线优先于死亡路线。

经济统计区分当前可用金币、即将失效的金币和持有资产。出售普通随从得到 1 金币，同时失去 1 单位随从资产，所以出售本身不会凭空增加经济分。如果随后结束回合，那 1 金币不计入保留价值，因为引擎在下回合重新设置金币。额外卖牌效果由真实规则执行后反映在金币、手牌或后续收入中，不预先重复计价。

## 比较操作路线

`compareRecruitLines` 接受同一公开局面、多条动作序列以及配对随机种子。每条序列都补上结束招募，执行真实招募规则与回合结束效果，再与“现在直接结束”比较。

这样可以比较“直接卖掉”和“卖掉→买牌→上场”的区别。没有禁止卖牌，也没有给模型动作偏好额外加分。不读取对手隐藏阵容、真实隐藏牌池或真实随机状态。涉及随机操作时使用公开信息重建的模拟环境，报告是模拟样本均值，不是置信结论。

任何种子下无法完成的路线都标记为不可比较，不会只挑成功样本来排名。无法公开重建的发现或英雄效果会报告具体原因。未知效果不伪造收益。

## 已验证

- 类型检查通过。
- 新评分器 8 项规则测试与现有招募模拟器 7 项测试，共 15 项通过。
- 记录的 28 个 `buy→play→sell→freeze→end` 开局保存在 `rl/fixtures/basic-opening-cases.json`。来源是观战 1024 层第 175 次保存的权重。
- 27 个可比较样例的“卖掉并结束”都低于“保留并结束”。1 个斯卡布斯样例因公开重建限制排除。结果见 `rl-basic-evaluation-20260916.json`。
- 1/4 腐皮豺狼人案例，卖掉并结束相对保留为 **−6 分**：场面少 5 分，保留资产少 1 分，未花的 1 金币在结束后不计分。
- 满场换牌测试确认：单独卖弱随从得分下降；卖掉、买入并打出强随从，整套操作得分上升。

这些案例用于验证计算和诊断旧模型，不能当成独立的棋力评测集。尚未测量完整对局平均名次、前四率或吃鸡率。

## 本地使用

复跑开局样例：

```bash
npx tsx scripts/audit-basic-openings.ts /tmp/basic-opening-result.json
```

评分指定局面，输入 JSON 的 `entities` 是 `observeEntities` 或训练模拟器输出的公开实体数组：

```json
{
  "entities": ["实际公开实体数组，请替换此示意值"],
  "phase": "recruit",
  "weights": { "attack": 1, "health": 1 }
}
```

```bash
npx tsx scripts/evaluate-basic-position.ts request.json result.json
```

比较路线时，输入 `lines: [{"name":"keep","actions":[]},{"name":"sell","actions":[29]}]`，其中动作 ID 必须来自当前 `rl/actions.ts`。可以再提供 `seeds`，默认使用四个固定配对种子。脚本不会启动训练或连接线上服务。

## 当前边界

身材总和只能粗略描述战力。圣盾、风怒、复生都是公开写出的近似加分。亡语、战斗触发、站位、种族配合、毒和对手克制尚未完整估价；手牌法术不凭购买价获得虚构资产分。血量与护甲会报告，但目前不为未致死的掉血赋予权重。未来成长、升本时机和刷新期权也没有精确估计。

下一回合收入只计算规则中的基础收入与已知额外金币，不预测回合开始触发。酒馆等级的固定加分及刷新、折扣加分需要后续完整对局校准，不能直接宣称高分路线就有更好名次。后续已通过有界评分差值接入完整对局 PPO，使用说明见 [训练接入](rl-basic-feedback.md)。独立评分器仍不直接替代线上策略选择。
