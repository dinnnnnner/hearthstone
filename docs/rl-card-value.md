# 结合阵容的逐牌金币估值

`--streaming --card-value` 或 `TAVERN_CARD_VALUE=1` 启用 `card-cash-v1`。保留已有策略、价值网络、优化器动量和历史池，增加轻量逐牌估值头及策略输入投影，不需要从零重训。当前覆盖随从，法术不在本版金币估值标签范围内。

## 对照含义

从真实采样保存的完整八人局面抽样，默认25%的分叉根局面各选择一张牌，轮换商店、手牌和场上随从。

- 商店随从必须当前可以买。卡牌分支执行真实购买，包含实际购买费用和购买触发。金币分支移除这次报价，将余额设为“原金币 − 实际购买费用 + 对照金币数”，再允许策略自行选择操作。这是在估算本次购买的总价值，没有假设所有随从的购买费用都固定为3金币。
- 手中或场上的随从，卡牌分支保留当前牌；金币分支直接移除该牌并补入对照金币。移除不触发出售效果，因为要比较完整持有价值。保留分支可以通过真实出售获得金币及卖牌触发。

移除的有限牌池副本归还共享池。金币不能超过该玩家当前金币上限，原局面和其随机流保持不变。虚拟资源替换仅用于辅助评估，不计为实际操作，不进入PPO，不产生额外游戏奖励。模型输入只有对应席位的公开观察。

买入战吼牌时，后续推演可以包含打出及铜须重复战吼。牌已经打出时，历史收益已经体现在原金币、手牌、属性等状态中，两个分支保留这些既得资源，不会把过去战吼收益重新加一遍。

## 金币单位与误差

对照金币网格为0、1、2、3、4、6、8、12，受当前金币上限限制；网格未包含上限时补入可用上限。至少4次配对推演，最多沿用分叉预算12次，默认向后推演2回合。没有结束时使用冻结价值网络的后续估值，结束时使用真实名次，并计入尚未发生的升本节奏奖励。

每个金币数量与卡牌分支比较平均回报，做单调拟合，插值得到两者效果相当的金币数。这个数是当前策略、局面和推演范围下的金币等价估计，不是把名次分直接叫作金币，也不是市场售价。

如果最高金币档仍不足以替代卡牌，只训练估值下界；若零金币已经更好，只训练上界。对照曲线过于平坦、严重不单调或有任何分支截断时不给精确标签。配对标准误差用于降低训练权重，不能视作棋力或价格可靠性保证。早期价值网络和后续操作较弱时，卡牌估值也会偏差，需要持续对局结果校准。

辅助损失为加权Huber，默认系数0.1；区间外才计算上下界损失。估值作为额外输入参与买牌、出牌、卖牌决策，PPO学习如何使用它。没有固定买入阈值，没有按估值总和奖励囤牌。编码器同时由正常对局训练。

## 检查结果

检查点在 `model_spec.card_value_head` 中记录版本，`config.card_value` 保存采样比例、金币网格和损失权重。`metrics.jsonl` 的 `card_value` 记录模拟数量、有效标签、截断和辅助更新。

`card-values-*.json` 记录公开牌面、卡牌ID和位置、购买或剩余持有模式、对照结果、金币估值标签、上下界及当前模型预测。初始预测为0，不能把尚未训练的输出当成已校准的价格。有限样本通过不代表模型已经学会铜须配合。

训练仍有每席每回合64次总操作限制，冻结1次、换位6次。总次数上限会限制长经济循环，这次新增估值没有改变操作规则。
