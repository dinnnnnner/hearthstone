# 恶鳞套餐没有给牌

`BG28_606` 恶鳞套餐的描述是随机获取 3 张塑造法术。原实现让它进入所有对局的酒馆法术池，但结算时只从本局随从池选择塑造法术来源。没有纳迦的对局没有候选，因此使用后不给牌。旧测试辅助函数把所有种族加回随从池，掩盖了这个情况。

修复后，酒馆刷新、随机获取与发现共用的 `drawSpell` 排除无纳迦对局的恶鳞套餐。已经存在于旧存档手牌中的套餐仍可使用：本局没有塑造法术来源时，从当前赛季已实现的塑造随从中选择来源。保留正常对局的候选、手牌上限、法术效果与有效期；生成法术不消耗随从池数量。

[卡牌资料](https://hearthstone.wiki.gg/wiki/Battlegrounds/Spitescale_Special)注明该法术只出现在有纳迦的对局。项目固定版本数据 `src/season/snapshot.json` 的卡号、中文名称、费用与效果一致。

新增 3 项回归测试。修复前无纳迦结算和出现条件两项失败；修复后通过，另覆盖三张牌可用、唯一实例、随从池不变、手牌不足与纳迦数量耗尽。135 项游戏测试、53 项服务器测试与前端构建通过。公网浏览器使用预置的无纳迦本地练习存档，实际点击施放后出现 3 张塑造法术，页面无错误。此浏览器测试没有修改线上玩家房间。

前后端发布 `20260914T053630Z`。公网 HTML、JS、CSS 哈希与构建一致，服务器包哈希一致。线上已有房间恢复并继续下一回合，三个人机模型健康，SECTOR PID 未改变。详情见 `docs/spellcraft-deployment-20260914.json`。
