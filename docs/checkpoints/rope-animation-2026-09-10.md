# 招募阶段烧绳

版本标签：`rope-animation-2026-09-10`，基于 `pool-powers-2026-09-10`。

人机匹配和好友房在招募最后 20 秒显示燃绳。火头沿绳向右移动，已烧部分留下灰烬；最后 5 秒加强火光和倒计时提示，到零时出现燃尽余烬，并显示等待战斗。提前结束招募、淘汰或进入战斗后收起效果。本地练习仍可自由结束回合，不新增倒计时。

绳子和顶部倒计时使用服务器的 deadline 与 serverNow，再用浏览器的 performance.now 计算收到快照后的经过时间，避免两台设备的系统时间差。收到新快照、刷新、重连和切回后台均可恢复进度，不会从头烧绳。到零由服务器结算，前端动画不自动发送结束请求。

效果使用 CSS 编织绳、火焰、火星和灰烬，无额外图片、视频或持续网络请求。100 毫秒更新一次的状态只在烧绳组件内，不重绘卡牌或运行规则引擎。桌面、手机横竖屏及旧布局均接入，效果层不截获点击。系统减少动态效果偏好关闭火星、闪烁和过渡，仍显示准确的剩余时间。

浏览器验证覆盖 20 秒阈值、火头推进、最后 5 秒、燃尽后等待服务器、进入战斗和下一回合清理、刷新重连、后台恢复、提前结束、三种布局和减少动态效果。时间边界测试使用真实房间模型生成的响应与受控浏览器时钟；在线人机、双人和八人房另用实际服务回归。

本次仅发布前端。线上主页沿用发布前内容，酒馆后端与 SECTOR 均不重启。具体发布目录和验证结果见 [deployment.json](../deployment.json)。
