# 召唤效果修复

按项目 36.4.2 快照的普通与金色文本，检查当前可玩的随从、法术及已有英雄召唤操作。此次检查区分进入棋盘、获取手牌、从手牌临时登场、召唤数量和召唤物品质。未将快照里尚未启用的历史饰品加入游戏。

| 效果 | 修复后的行为 |
|---|---|
| 好斗的斥候 `BG32_330` | 战斗开始时，从手牌召唤一个保留增益及关键词的复制。金色仍只召唤一个，复制的攻击与生命翻倍。原手牌不变，复制只存在于战斗棋盘，满场时不召唤，也不等待后续空位。 |
| 飞行专家 `BG34_140` | 金色选择攻击最高的两张不同手牌，避免重复复制第一张。已达到解锁回合或等级的牌可以参与选择。 |
| 凶饿的觅食者 `BG27_556` | 金色选择攻击最高的两张不同鱼人手牌；满场时保留等待空位的行为。 |
| 金色增加数量的召唤 | 无害的骨颅、遗骸看管者、断手被遗忘者、森林游虫、嗡鸣害虫、绿松石飞掠虫、暴虐巨蝎、翩飞蝙蝠增加普通召唤物数量，不把它们升级为金色。 |
| 坎格尔的学徒 `BGS_012` | 金色召唤最先死亡的四个机械的原始版复制，保留各来源原有的普通或金色品质。 |
| 继承的亡语召唤 | 磁力合体和恩佐斯的鱼继承来源的召唤数量与品质，宿主或鱼本身的金色状态不会错误地把普通召唤物升级。金色鱼仍按已有规则复制两次亡语。 |
| 招募阶段亡语与复生 | 摧毁随从后，在其原位置依次插入亡语召唤物和复生随从；直接触发召唤时放在来源旁边。 |

拔线机、永恒召唤者、自动装配机、下水道老鼠头目及下水道老鼠、囤食土狼继续按各自文本召唤升级后的随从。狡猾的迅猛龙仍召唤一只并设置身材。致命打击者沿用按所记手牌召唤的操作。甲虫恩泽沿用战斗空位队列。亚煞极本来就同时“召唤并获取”，保留其手牌奖励；不能把所有与召唤相关的手牌写入一律删除。经典模式雄斑虎、鱼人猎潮者的战吼原本已直接进入棋盘。

斥候的手牌条件和复制文本也见 [Flighty Scout 卡牌资料](https://hearthstone.wiki.gg/wiki/Battlegrounds/Flighty_Scout)。此次精确行为以项目快照的明确文本和回归测试为依据，不声称验证了官方所有召唤与触发排序。
