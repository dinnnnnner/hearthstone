# 掉血刷新与关键词画面

版本标签 `refresh-keywords-2026-09-10`，前后端发布目录均为 `20260910T004855Z`。上一版 `heroes-pass-2026-09-08` 和更早的检查点保留。

舞蹈王子玛克扎尔的刷新结算原本允许以生命支付，但界面仍按金币判断按钮是否可用，造成零金币时无法刷新。同时，次数使用全场共用计数和最大值，多张随从不能分别提供次数，新打出的随从也会受到已有计数影响。

本版用 `refreshPayment` 统一金币费用、生命费用、剩余次数和提供效果的随从。普通每张两次、金色每张四次；免费刷新优先消耗，不扣生命也不占掉血次数。次数在回合开始时恢复，并随本地存档和房间快照保存。旧格式共用计数按场上顺序分摊到各随从，避免迁移后返还已经使用的次数。回溯者联动、自伤淘汰、名次及牌池归还继续由已有结算流程处理。

桌面棋盘、旧版桌面面板和手游面板均显示红色生命费用及剩余次数。次数耗尽后恢复金币费用。没有变更项目锁定的随从星级或原始卡面数据。

嘲讽改为独立的盾形金属护框，圣盾改为有反光和金色边缘的护罩，破盾外壳增加裂片。复生为青色光环与回转标记，烈毒/剧毒为绿色药瓶，亡语为骨色骷髅，风怒为蓝色风纹；附加能力中的亡语也会显示。装饰使用 CSS 与 SVG，不接收指针事件，也不覆盖战斗位移。破盾时刻和暂停、跳过仍由现有动画时钟控制，没有增加持续运行动画或素材下载。

恢复代码可执行：

```bash
git worktree add --detach ../hearthstone-refresh-keywords refresh-keywords-2026-09-10
```
