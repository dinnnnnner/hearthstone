# 游客与八人好友房版本

Git 标签：`online-rooms-2026-09-08`。旧的 `baseline-demo-2026-09-08`、`gameplay-board-2026-09-08` 和 `animation-pass-2026-09-08` 标签继续保留。

前后端发布版本为 `20260908T055800Z`。线上入口为 https://8.153.150.101/tavern/，房间服务为 `bobs-tavern`，监听 `127.0.0.1:8787`。发布和回滚步骤见 [部署说明](../../deploy/README.md)，具体路径与验证数据见 [部署记录](../deployment.json)。

本版包含游客身份、玩家对七名规则人机、最多八名真人的好友房、房间码、准备与房主开局、空位补人机、统一牌池与双方战斗结算、掉线恢复和服务快照。在线对局与原本地练习存档独立。人机尚未使用强化学习。

验证通过 46 项引擎与状态测试、7 项服务测试、22 项本地浏览器测试和 7 项公网浏览器场景。满房场景用八个独立浏览器缓存验证同步战斗，耗时 12.1 秒。公网首次图片加载曾使操作请求超时，现使用 320 像素 WebP 界面图片、HTTP/2 和对局请求优先级。原画及完整卡面保留。

查看该版代码可新建隔离目录，不改当前工作区：

```bash
git worktree add --detach ../hearthstone-online-checkpoint online-rooms-2026-09-08
```

游客凭证和房间快照保存在服务器独立数据目录，Git 标签不包含这些运行时数据。未来 RL 接口与已知模拟差异见 [AI / RL 记录](../rl-roadmap.md)。
