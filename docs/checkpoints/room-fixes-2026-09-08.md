# 房间边界修复与同步优化

版本标签 `room-fixes-2026-09-08`，线上发布 `20260908T062430Z`。上一版 `online-rooms-2026-09-08` 及更早的 Demo 标签保留。

本版统一处理真人和人机的自伤淘汰、名次与牌池归还。招募开始时保存配对，战斗使用同一配对；对手中途退出则改打幽灵，其他配对保持。全体真人连续离线五分钟后回收房间，自动回合推进不会延长宽限期。

客户端按回放标识缓存战斗帧，后续更新省略已缓存的帧，刷新页面仍可获取完整回放。棋盘状态按版本复用，倒计时独立渲染。存档使用异步串行写入、合并变更和原子替换，未变房间复用序列化缓存。旧格式存档仍可恢复，并补一次离线宽限期。

通过 46 项引擎测试、16 项服务测试、22 项本地界面测试及 7 项公网测试。新增九项服务回归测试，覆盖自伤淘汰、离线回收、重连、配对、幽灵、回放缓存、旧存档迁移，以及并发保存和失败重试。公网八人房验证耗时 11.6 秒。

本机构造的 180 帧战斗中，初次响应为 352115 字节，复用回放后的响应为 6642 字节；gzip 分别为 5938 和 1653 字节。这是指定场景的数据量对比，不代表整服容量压测。

恢复代码可执行：

```bash
git worktree add --detach ../hearthstone-room-fixes room-fixes-2026-09-08
```
