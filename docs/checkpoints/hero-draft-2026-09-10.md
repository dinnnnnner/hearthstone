# 自选英雄与随机四选一

保存标签：`hero-draft-2026-09-10`。

大厅增加英雄选择方式，适用于人机匹配和好友房。自选英雄沿用原流程；随机四选一在开局前向每位玩家发放四位候选，每张卡下方可以单独刷新。支持桌面四列与手机两列，卡面复用现有素材。

房间保存 `heroSelection`，玩家座位保存 `heroOffers`。服务器把所有玩家当前候选和已选英雄视为占用，抽取时排除这些英雄。刷新只替换指定位置，先抽取新英雄再释放旧英雄；已刷新掉的英雄可以在之后重新进入候选。当前同时存在的候选不会重复，实际参战英雄也不会重复。

刷新已选位置会清空选择和准备状态。服务器验证操作者、候选归属、位置及原英雄，过期刷新请求被拒绝。尚未选择英雄时不能准备或开局。候选仅发给所属玩家，其他玩家只能看到已选英雄。

重连和服务器重启保留候选及选择；再来一局重新发放四位候选。离开待开局房间时释放该玩家的候选。旧存档和未指定选择方式的旧客户端默认自选英雄。人机房在随机模式下等待玩家确认再补入七名人机。

芬利的英雄技能发现保持独立，不使用开局英雄占用池。回归测试验证了自然生成的芬利候选能包含同房已占用英雄的技能，并成功选择，同时保留所有座位的英雄身份。

验证：生产构建、28 项服务端测试、9 项本地浏览器检查通过。服务端覆盖八人 32 个候选、128 次刷新、释放候选、重连、重新开局、非法 API 请求及芬利例外。本地真实服务验证多人同时刷新与重复提交，另外检查原有八人联机。公网最终结果记录在 [deployment.json](../deployment.json)。
