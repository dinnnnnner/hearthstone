# 当前规则与公开战况训练包

本次更新沿用 v3 网络和动作编号，更新软件包实际依赖的游戏引擎与房间服务。

- 纳入工作区当前卡牌效果、生命加剩余初始护甲排名、法术护甲消耗，以及八人七回合轮转、奇数人数尸体配对和击杀者排除规则。
- 保持现有伤害保护：前 3 回合上限 5 点，第 4 至 7 回合上限 10 点，之后上限 15 点，剩余 4 人时解除。
- 新增八席最近两回合公开战况，包含阵容类型、种族数量、交战座位、胜负和伤害，覆盖实体网络与 MLP。双方当前招募阵容和手牌仍不可见。
- 观察版本为 4，实体版本为 3，MLP 为 3209 维，实体数 73，动作数 4316。

构建通过 `rl-dist/build.json` 记录每个实际依赖文件的 SHA-256，新排名、配对和战况模块参与指纹计算。归档内的 `checksums.json` 校验所有交付文件。

本地归档为 `rl-dist/tavern-selfplay-v3.tar.gz`。服务器新包目录为 `/root/autodl-tmp/tavern-selfplay-v3-scouting-20260911`，保留原 `/root/autodl-tmp/tavern-selfplay-v3` 和原模型。

旧规则模型不能直接续训或加入新版对手池；加载器会拒绝不一致的源码哈希。新包可以从头训练。若以后需要迁移旧模型，应单独实现权重迁移与评估，不能修改检查点哈希来冒充兼容。

验证中发现，历史第三饰品动作回放依赖旧规则，在当前规则下会遇到非法动作。保留原始回放文件，将自动回归测试改为直接创建第九回合领取第三饰品的场景，验证合法动作和输入容量。

在新目录运行：

```bash
./run-server.sh test
./run-server.sh train --output rl/runs/main --iterations 2 \
  --device cuda --workers 4 --games-per-iteration 8 --max-actions 64
```

上述训练命令用于后续手动启动，本次接入只执行有限的验证任务。
