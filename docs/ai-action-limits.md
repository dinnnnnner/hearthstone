# 人机每回合冻结和换位限制

源码和新训练包默认启用以下规则：

| 动作 | 上限与行为 |
| --- | --- |
| 冻结 / 解冻 | 每回合最多 1 次手动切换，操作后只能结束招募 |
| 换位 | 每回合最多 6 次，将一个随从插入指定位置计 1 次 |
| 立即撤销换位 | 屏蔽恢复上一次换位前完整顺序的动作，即使换了另一个随从来操作 |
| 无效换位 | 不改变位置或目标无效的动作被拒绝，不消耗次数 |
| 出牌放置位置 | 不计为换位 |

限制仅适用于在线人机及离线自我对战的策略席位，玩家手动操作不受限制。刷新自动解除冻结不消耗手动切换次数，也不恢复已用次数。购买、出牌、刷新等成功操作可以结束“立即撤销”的判定，但不能重置本回合总次数。

只有商店中存在当前金币买不起的随从或金币法术时，才允许从未冻结切换为冻结。使用引擎实际费用，包含英雄能力、折扣和免费购买；用生命值购买的法术不算金币短缺。手牌已满本身不构成冻结条件。已有冻结允许取消一次，取消后同样只能结束招募。英雄效果自动冻结不消耗手动次数。

这只是冻结资格，不代表买不起的牌就值得保留。模型仍在冻结与直接结束之间选择。`freezeOffers` 给出买不起的商店槽位；阵容价值由模型学习，规则不自动冻结。

## 执行与观察

`src/ai-action-limits.ts` 定义规则，`Game.aiActionUsage` 保存本回合计数和上次换位前的顺序。规则引擎只在操作成功后更新结果状态。合法动作生成器提前移除不可执行的冻结和换位，实际执行时再次校验。

计数跟随房间存档保存；下一回合通过回合编号恢复额度。旧在线房间没有这项记录时从升级时的零次使用开始，无法推断升级之前已做过多少次。各席位独立计数。

73 实体模型的全局字段新增 `aiActionLimits`，含版本 2、`freezeRemaining`、`moveRemaining`、`freezeClosing`、`freezeOffers`，以及可选的 `undoOrder`。顺序用当前己方战场槽位表示，不把随从实例 ID 发给模型。当前 64、256、1024 层实体网络的可变字段编码能直接接收，不需要增加网络参数。

旧的 3209 维平坦 MLP 和 `legacy-v3` 投影保留原输入布局，仍执行动作掩码限制，但不增加专门的剩余次数输入。当前三个深层模型均使用实体投影。

## 搜索隔离

公开局面重建恢复实际剩余额度和立即撤销状态；不从零重新给满次数。每条模拟操作只更新分支副本。模拟重置、分支试探和合法性预检均不会修改真实对局。

搜索协议升级为 `own-recruit-freeze-close-v3`。发布时需要一起更新公网服务、Python 搜索服务和 Node 搜索 bundle，健康检查会拒绝旧搜索协议。模型权重可以先保持现有版本。

## 训练与兼容

新建 `SelfPlayEnv` 默认启用限制。仅为了回放旧回归用例，底层模拟器保留 `aiActionLimits: false` 选项；常规训练无需设置它。

本次改变合法动作和公开字段，因此新 bundle 的源码 / 规则哈希会变化。已有完整 PPO 检查点仍受严格的哈希检查保护，不能直接拿新 bundle 无检查续训。现有运维入口使用服务器冻结的运行目录，更新 Git 不会自动替换该目录或重启训练。

采用新限制续训时，需要先停止旧训练、保留旧检查点和软件包，再显式迁移到新实验目录，核对网络和动作编码、迁移历史对手及训练元数据，用新规则重新采样。不要混入旧规则下采集但尚未更新的轨迹。

2026-09-15 的第一版次数限制已完成公网、搜索和 Blackwell 的版本切换，三份训练检查点通过专用 `tavern_rl.migrate_action_limits` 工具迁移。工具只接受本次核对过的旧、新源码与规则哈希，要求其余模拟器元数据及所有历史对手的动作、实体编码一致；输出到新文件，并在重新加载后核对保留状态的摘要。迁移记录保存在训练配置中，普通检查点加载器仍严格检查版本。路径、验证和回滚说明见 [部署记录](ai-action-limits-deployment-20260915.md)。

建议先保留当前权重进行适应训练，并用固定对手、种子和相同限制比较训练前后名次。减少循环是规则直接产生的效果，不能单独作为棋力提升证据；从零训练可以作为另一个对照实验。

本地构建、规则、房间、搜索、Python 特征编码和两局 PPO 验证见 [验证记录](ai-action-limits-validation-20260915.json)。三种深度的既有推理权重均通过合法动作与记忆隔离检查。这些结果不构成棋力评估。

本次收尾冻结规则在第一版上继续迁移，工具仅额外允许经过核对的 v1 → v2 哈希组合。现有权重、优化器、随机状态、历史池和累计局数保留；新规则重新采样。每轮训练日志新增 `action_counts` 和 `learner_action_counts`，分别统计所有席位与当前学习策略的动作。当前仍用名次奖励训练，尚未加入金币搜索的蒸馏标签。

收尾冻结上线及续训的路径、时间和验证见 [第二次部署记录](ai-freeze-close-deployment-20260915.md)。
