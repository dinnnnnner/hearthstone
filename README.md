# 鲍勃的酒馆

酒馆战棋 Web 应用，支持游客登录、人机对战、八人好友房和本地练习，使用 React、TypeScript 和 Vite。在线对局使用第 14 赛季部分规则，数据锁定 36.4.2 / build 251332，核对日期为 2026 年 9 月 8 日。本地练习也可切换经典精选模式。

## 已部署入口

- 游戏大厅：https://8.153.150.101/
- SECTOR：https://8.153.150.101/sector/
- 酒馆：https://8.153.150.101/tavern/

主页和酒馆由同一个 Nginx 提供静态文件。游客与在线房间由独立的 `bobs-tavern` Node 服务处理，Nginx 通过 `/tavern-api/` 转发。SECTOR 的进程及 `/ws`、`/api/`、原资源路径保持原有路由。线上酒馆可点击顶部“返回游戏大厅”；SECTOR 左侧标志也可返回主页。

部署配置、发布与回滚方法见 [deploy/README.md](deploy/README.md)。

## 游客与在线对战

首次进入填写昵称，点击“游客进入”。游客凭证保存在当前浏览器，服务器保存对应身份和房间。刷新页面可以回到原房间。

- **人机匹配**：选择英雄，直接开始一局玩家对 7 名人机的八人对局。
- **好友房**：创建后分享 6 位房间码。最多 8 名真人，空位由人机补齐；朋友选英雄并准备后，由房主开局。
- 招募阶段为 90 秒，所有存活真人提前结束招募时立即交战。动画播放后点击返回酒馆；等待所有真人确认或播放期限到达后进入下一回合。
- 退出进行中的房间计弃权；掉线可以重连，但不会暂停全桌倒计时。超时会自动处理未选发现与饰品并结束招募。
- 全体真人连续离线 5 分钟后回收房间、释放对局名额；宽限期内重连会保留对局。招募开始时确定对手，对方中途退出则改打幽灵阵容。
- “继续本地练习”使用原浏览器存档，不会被在线对局覆盖。棋盘顶部的“对战大厅”按钮可以返回房间。

在线房间使用服务器统一牌池和战斗结算。同一场战斗只模拟一次，双方收到视角相反的同一组快照。人机使用购买、出牌、升级、发现和英雄技能等合法动作。当前是部分赛季规则与本项目的轮换配对，不是官方匹配服务器；奇数存活玩家会遇到已淘汰玩家的幽灵阵容。

## 运行

```bash
npm install
npm run dev:server          # 另一个终端，默认 127.0.0.1:8787
npm run dev -- --port 5174
```

打开 http://localhost:5174。在线进度保存在房间服务，本地练习保存在当前浏览器。支持手机、拖动招募与站位调整、战斗回放。

```bash
npm test          # 规则场景与有限牌池守恒测试
npm run test:server # 房间、权限、牌池、双方技能和重启测试
npm run build     # TypeScript 检查与生产构建
npm run test:e2e  # 启动开发服务后运行浏览器测试
```

浏览器测试默认连接 5174，可通过 `TEST_BASE_URL` 修改。首次运行可能需要 `npx playwright install chromium`。

## 实战棋盘与手机操作

默认使用木质棋盘，酒馆随从和双方战场显示为椭圆棋子。招募与战斗在同一场景进行，包含蓄力、碰撞、回位、接触时掉血、圣盾碎片、死亡退场、召唤、增益和三连汇聚。英雄伤害也通过撞击播放，购买与出牌有飞行过渡。战斗支持暂停、0.75 / 1 / 2 倍速及跳过，音效可以关闭。

- 酒馆随从拖到手牌区购买，也可双击购买。
- 手牌拖上战场打出；有目标的法术可以直接拖到适用的随从上。
- 场上随从拖动调整站位，拖向鲍勃出售。
- 点选棋子或手牌可查看技能，使用招募、打出、发动、出售及左右移动按钮。
- 黑暗发现位于棋盘右上方，饰品位于英雄左侧，英雄技能位于右侧。

嘲讽使用独立盾形金属护框，圣盾使用带反光的金色护罩，破盾时沿用战斗接触时刻播放碎裂。复生、烈毒/剧毒、亡语和风怒使用不同的图标与颜色，附加亡语也会显示。装饰图层不拦截拖动或点选。

支持手机横竖屏。手牌横向滑动浏览，向上拖动出牌；也可完全用点选操作。顶部全屏按钮在浏览器支持时进入全屏。设置中关闭“实战棋盘”即可回到旧版面板，再选择标准或手游布局。切换布局不会清除对局存档。

表现层使用 React、原生 SVG、Web Animations API 与按需运行的 Canvas 粒子。动画在浏览器执行，棋盘沿用本地卡牌原画。参考片段、实现取舍与验证记录见 [docs/gameplay-presentation.md](docs/gameplay-presentation.md)。

## 进入游戏与加载画面

打开页面即显示酒馆纹章、旋转金环和加载提示，脚本下载失败时可点击重试。进入棋盘前按实际完成数量显示当前英雄、随从与饰品图片的准备进度；最多同时加载三张，等待三秒后可手动进入，八秒后自动进入，图片缺失不会卡住对局。已准备的图片在本次访问中复用，后续回合不重复等待。

棋盘增加木板边缘明暗、皮革底色、黄铜铆钉和中央刻纹，卡框、手牌和操作按钮的阴影与按压反馈也已调整。加载画面适配手机横竖屏，并尊重系统“减少动态效果”设置。

## 当前赛季实现范围

| 内容 | 已接入 |
| --- | --- |
| 随从图鉴 | 234 种当前补丁单人模式 1 至 6 星随从 |
| 可玩随从 | 234/234 种单人模式 1 至 6 星随从已接入规则 |
| 酒馆法术 | 67/67 种可购买和施放 |
| 英雄 | 89/116 名，采用固定补丁的技能费用、生命值和护甲 |
| 黑暗之赐 | 21 种已实现效果，使用第 3 回合起的发现及星级规则 |
| 饰品 | 23 种已实现效果，第 6、9 回合分别选取小型、大型饰品 |

购买、刷新、冻结、出售、升级、手牌上限、战场上限、有限随从池与三连已接通。三连合并增益、关键词及磁力材料，打出金色随从后领取高一星的发现奖励。

技能引擎支持战吼、亡语、进击、发动、塑造法术、磁力、复生、烈毒、圣盾、嘲讽、风怒、顺劈、抉择、上锁宝箱、鱼饵、手牌参战、法术重复施放及种族成长。英雄覆盖与未实现名单见 [规则覆盖报告](docs/rules-coverage.json)，可运行 `npx tsx scripts/rules-coverage.ts` 重新生成。

舞蹈王子玛克扎尔的掉血刷新在零金币时也可使用，按钮显示生命费用和剩余次数。普通随从每张提供两次、金色每张四次，按随从分别计数并在下一回合恢复；免费刷新优先消耗，不占掉血次数。旧存档的已用次数会迁移，刷新页面不会重置。

新英雄已接入本地练习、人机匹配和好友房。技能按钮显示动态费用、解锁条件和使用次数。布莱克松与因葛每回合可使用两次；雷诺整局只能点金一次，保留额外属性与原有牌池份数，不生成三连奖励。伊莉斯每次使用后涨价，齐恩瓦拉每使用三张元素牌减少升级费用，计数随存档和房间快照保存。

芬利开局发现一个技能，阮大师每回合从两个技能中选择，吉恩在第 4 回合连续发现两个技能。身份揭晓可更换主技能，吉恩的第二技能保留。两项技能各自计算费用、次数和目标，购买费用、刷新、升级与战斗被动读取当前技能；原英雄的头像、生命和护甲不变。发现候选仅包含已实现且适合本局种族的技能，尚未接入官方完整候选权重及禁用组合。雷诺的整局次数、伊莉斯涨价、齐恩瓦拉进度随技能记录保留。诺兹多姆未用的免费刷新不会跨回合累积。

巴琳达使以友方随从为目标的法术施放两次，金色施放三次，多张不会相乘。每次重施前重新验证目标；宰割在第一次消灭目标后停止。抉择通过独立选项和目标选择结算，支持桌面、手机、服务器自动选择和断线恢复。惊喜元素参与元素三连；钟表先生只需两个复制，打出金色随从改为获取酒馆币。上锁宝箱五回合后打开，也可由随从技能提前开箱；搜寻时光和玛维的手牌会显示解锁回合。

发现和定向取牌占用有限池；明确写作复制或生成的奖励不额外扣池。点金保留原份数与额外属性，不发放三连奖励。旧对局继续使用创建时的有限池，新开一局才能抽到新增随从。

每局开放五个随从类型。本地练习保证所选英雄需要的类型；在线房间保证所有入座英雄需要的类型，再随机补足五种。随从按剩余份数加权抽取，AI、酒馆、手牌、战场、磁力材料及发现候选共同占用随从池；刷新、出售和未选择的发现候选归还牌池。

| 星级 | 每种随从份数 | 酒馆随从栏位 | 初始升星费用 |
| --- | --- | --- | --- |
| 1 | 15 | 3 | 5 |
| 2 | 15 | 4 | 7 |
| 3 | 13 | 4 | 8 |
| 4 | 11 | 5 | 9 |
| 5 | 9 | 5 | 10 |
| 6 | 7 | 6 | 已满级 |

酒馆法术独立提供一个栏位，按各星级 5、7、9、11、7、5 的每种份数加权。法术获取后即归还池中，因此不占用玩家持有的随从份数。战斗伤害先扣护甲，并采用前 3 回合 5 点、第 4 至 7 回合 10 点、之后 15 点的伤害上限，进入前四后解除。

仍不能称为整个赛季的完整复刻。常规 1 至 6 星随从池及酒馆法术已接入，但还有 27 位英雄、22 项黑暗之赐，以及完整饰品候选、权重和禁用组合未实现。未开放英雄包括伙伴、任务、时空扭曲和星际主题等需要独立内容池的英雄，完整名单在覆盖报告中。这里只验证已实现的结算与池守恒，尚未逐项对照官方客户端的所有交互顺序；不包含双打和陌生玩家排位匹配。

本地练习模式的七名 AI 从共享池招募，按回合提升等级，轮流与玩家交战。它们尚无完整经济决策、三连、英雄技能和互相交战流程。复杂战斗触发采用本项目的事件处理逻辑，不能将模拟结果等同于官方客户端结果。经典精选模式保留最初 32 种历史随从及 8 名历史英雄规则。

## 网上卡面素材

已按真实卡牌 ID 从 [HearthstoneJSON 插画服务](https://hearthstonejson.com/) 下载素材，运行时读取本地文件。当前赛季的 507 个随从、法术、英雄、黑暗之赐与新饰品 ID 均有原始插画；此外下载了衍生牌与经典模式插画。

界面使用 `public/thumbs` 中的 320 像素 WebP 图片，556 张共约 8.9 MB，是原始 PNG 体积的 6.6%，降低多人同时进房时的流量。原画仍保存在 `public/art`。更新下载素材后，运行 `python3 scripts/build-thumbnails.py` 重新生成界面图片，需要本机安装支持 libwebp 的 ffmpeg。

192 张中文完整卡面保存在 `public/cards`。部分卡没有中文渲染，界面会使用 `public/art` 中的真实原画搭配锁定补丁的中文数据排版。点击卡牌详情中的“查看网上卡面与素材来源”可查看原始素材和来源链接。素材站的完整卡面使用 latest 路径，可能与锁定补丁不同，游戏结算始终采用快照数值。

美术与商标属于原权利人。本项目为非官方练习作品。

## 更新与文件

```bash
python3 scripts/sync-season.py           # 下载锁定 build 并生成中文快照及 SHA-256
python3 scripts/download-season-art.py   # 下载原画和可用的中文完整卡面
```

- `src/season/snapshot.json`：版本固定的原始数据，不等于全部技能均已实现。
- `src/season/catalog.ts`：当前赛季可玩卡牌与技能声明。
- `src/season/engine.ts`：当前赛季招募、技能、发现、饰品与战斗结算。
- `src/season/Panels.tsx`：赛季操作区、法术栏、饰品及卡面来源。
- `src/table/`：独立棋盘、手势、战斗动画、粒子与音效。
- `src/online/`：游客入口、匹配大厅、好友房与在线状态同步。
- `server/rooms.ts`：房间权限、统一牌池、八人配对、人机策略和回合推进。
- `server/index.ts`：鉴权 HTTP 接口、快照持久化、请求大小和频率限制。
- `src/data.ts`、`src/engine.ts`：共享类型与经典规则。
- `src/App.tsx`、`src/styles.css`：界面、交互、回放及浏览器保存。
- `docs/season-provenance.json`：数据来源、build 和哈希。
- `docs/art-manifest.json`：素材请求及源站缺失记录。
- `src/season/engine.test.ts`、`src/engine.test.ts`、`tests`：规则与浏览器验证。
