# 鲍勃的酒馆

酒馆战棋 Web 应用，支持游客登录、人机对战、八人好友房和本地练习。前端使用 React、TypeScript、Vite，Node.js 管理在线房间，Python / PyTorch 负责神经网络训练和推理。

项目使用固定的 36.4.2 / build 251332 数据快照，实现第 14 赛季的部分规则。它是非官方练习项目，规则覆盖与官方客户端仍有差异。

## 本地运行

安装 Node.js 和 npm 后，在仓库根目录执行：

```bash
npm ci
npm run dev:server
```

再开一个终端启动前端：

```bash
npm run dev
```

服务端默认监听 8787，前端地址以 Vite 输出为准。本地练习可以直接在浏览器运行；在线房间需要服务端。

```bash
npm run build          # 类型检查和前端构建
npm test               # 游戏规则和界面逻辑
npm run test:server    # 房间、接口、推理接入及持久化
npm run test:rl        # 训练环境和动作契约
npm run test:search    # 招募搜索
```

浏览器测试使用 `npm run test:e2e`，首次运行需安装 Playwright Chromium。服务器部署和 `/tavern/` 子路径构建见 [部署说明](deploy/README.md)。

## 游戏和人机

在线房间统一管理八席位、共享有限卡池、配对、战斗、护甲与生命结算。人机之间也会交战、扣血和淘汰。玩家可以选择普通神经网络或带回合搜索的版本。公开战况记录最近两回合的交战座位、阵容类型、胜负和伤害。

当前规则覆盖为 234/234 种常规随从、67/67 种酒馆法术、89/116 位英雄，另有 21 种黑暗之赐和 23 种饰品。AI 使用单独维护的 15 英雄名单；这不限制已开放的玩家英雄列表。名单是暂定训练子集，不能当作当前赛季的实时强度榜。

伤害结算按当前引擎执行：存活人数超过四人时，第 1～3 回合上限 5 点，第 4～7 回合上限 10 点，之后上限 15 点；进入前四后解除。伤害先扣护甲。覆盖数量不代表所有触发顺序均已与官方逐项核验，详见 [规则覆盖报告](docs/rules-coverage.json)。

本地练习的脚本 AI 与在线神经网络使用不同的决策方式。脚本 AI 不具备完整经济、三连和技能决策；离线 PPO 对手使用神经网络。

## 模型概览

三个深度模型都使用 73 个公开状态实体、两层 Transformer、每席位独立的 GRU 记忆，以及分开的策略和价值残差分支。策略在 4316 个动作编码中选择合法动作。

| 模型 | 策略分支 / 价值分支的全连接层数 | 参数量 |
| --- | --- | ---: |
| 64 层 | 64 / 64 | 3,421,950 |
| 256 层 | 256 / 256 | 9,860,862 |
| 1024 层 | 1024 / 1024 | 35,616,510 |

参数量对应当前宽度 128、固定词表的模型。层数名称不包含 Transformer、GRU、归一化和输出头。更深的模型是否更强，需要固定对手评估。

模型能看到当前回合、剩余金币、升本费用、自己的手牌和场面，以及公开的历史战况。训练让模型学习如何利用这些信息，并不直接规定“前期升本、后期找核心卡”的动作顺序。

人机每回合冻结切换 2 次、换位 6 次，并屏蔽立即撤销换位。玩家不受限制。2026-09-15 已同步切换公网、三个搜索服务和训练运行目录，见 [动作限制](docs/ai-action-limits.md) 与 [部署记录](docs/ai-action-limits-deployment-20260915.md)。

目前训练流程是三份独立 PPO 模型交换冻结历史对手。每局通常四席由当前策略控制，另外四席从自身历史与其他深度模型中抽样。当前续训奖励第一名 +2、第八名 −1，已删除结束回合剩金币扣分及对应采样开销。真人模仿学习按单独阶段接入，回合搜索用于在线推理。

## 训练与部署

日常操作在本机执行：

```bash
python3 scripts/tavern-ops.py status
python3 scripts/tavern-ops.py train --hours 4
python3 scripts/tavern-ops.py stop
python3 scripts/tavern-ops.py publish
```

这些是分别按需执行的命令。`publish` 要求训练停止，并检查线上活跃对局。它更新三个普通模型，搜索版保留独立的冻结版本。完整参数、目录和回滚说明见 [日常运维](docs/tavern-operations.md)。

当前部署分工为租用 Blackwell 服务器训练、`100.97.24.15` 计算网页模型、公网服务器承载页面和房间并通过 SSH 隧道请求推理。训练完成后需发布，网页才会使用新权重。部署地址和版本记录与可复用的训练命令分别维护。
